## ⚡ 遊戲特色與核心機制

### 1. ☁️ 經典頂鈴鐺系統 (Bell Juggling)
射擊飄浮白雲會掉出鈴鐺，**持續射擊鈴鐺可使其向上彈跳並變換顏色**：
- 🟡 **黃色鈴鐺 (Yellow)**：分數加成（+500 ➔ +1000 ➔ +5000 ➔ +10000 分！）
- ⚪ **白色鈴鐺 (White)**：升級為 **Twin Cannon (雙發子彈)**
- 🔵 **藍色鈴鐺 (Blue)**：戰機獲得 **Speed Up (加速)**
- 🟢 **綠色鈴鐺 (Green)**：獲得 **Shadow Clones (殘影分身)**，跟隨戰機同步射擊！
- 💖 **粉紅鈴鐺 (Pink)**：補滿 **Barrier Shield (防護罩)**

### 2. 👑 關卡 Boss 戰 (Stage Bosses)
- 🧅 **Stage 1 Boss**: **【洋蔥大王 (King Onion)】** (得分 ≥ 300 觸發)
- 🍉 **Stage 2 Boss**: **【西瓜巨型獸 (Watermelon Mecha)】** (得分 ≥ 1000 觸發)
- 🫖 **Stage 3 Boss**: **【皇冠大茶壺魔王 (King Spice Teapot)】** (得分 ≥ 2500 觸發)

## 🕹️ 操作說明

### 💻 電腦端 (Desktop)
- **戰機移動**：`W / A / S / D` 或 `↑ / ↓ / ← / →` 方向鍵
- **子彈發射**：`Space` 空白鍵自動連發
- **極限防禦**：`E` / `Shift` 鍵
- **遊戲暫停**：`P` 鍵

### 📱 手機端 (Mobile RWD)
- **直接觸控拖曳**：手指在螢幕任意滑動即可順暢拖曳戰機，並自動發射子彈！
- **虛擬搖桿與按鈕**：使用左下角虛擬搖桿與右下角 `FIRE` / `BOMB` 按鈕操控。
